# 網頁儀器版面與解析度(駕駛台、教官站、情境編輯器)

> 規劃書第 7 章(駕駛台儀器)、第 9.1 節(教官站)、第 7.3 節(以內顯文書筆電為效能與版面基準)。第二十九輪(2026-11-22)以真實核心 +

## 1. 目標解析度

| 視窗(CSS px) | 代表的機器 | 備註 |
|---|---|---|
| 1366×768 | 船上文書筆電(最常見的低階面板) | 最嚴格:中段高度最小 |
| 1536×864 | 1920×1080 筆電在 Windows 125 % 縮放 | 教官筆電最常見 |
| 1600×900 | 1600×900 筆電 / 外接螢幕 | |
| 1920×1080 | 外接螢幕、100 % 縮放 | 瀏覽器視窗高度常不足 1080(工作列、分頁列) |
| 2560×1440 | 大螢幕 | 不可退步 |

1280×720 與 1024 寬以下只要求「不比原本差」(情境編輯器在 1150 px 以下自動改一欄)。

## 2. 各頁的排法

### 2.3 簡化教官模式、重播檢視、ECDIS、雷達、講評報告

更正(第二十九輪 L3):L2 時本節寫「各目標解析度下沒有被蓋住的控制項」,當時只量了**空白的初始畫面**。以同一份判定量
**載入紀錄後的重播檢視**與**「開始練習」後的簡化模式**,1366×768 都不通過(5d811a1 就有):重播檢視的事件串流只剩 38 px、六個篩選鈕被下一個面板蓋住
(真實點擊被攔截),講評摘要的表格被長指標名稱撐到約 1140 px 寬;簡化模式執行階段的 VHF 落在固定格列中給學員操作紀錄的那一列(約 88 px),
頻道 69–77、守聽選單、PTT、音量被 `overflow: hidden` 裁掉。L3 的修正:

- 簡化模式選擇頁:情境面板帶 `simple` 屬性,詳細區優先取自然高度(講評引導問題的標題不被推到可見範圍外),清單吃剩餘高度、至少 96 px。
- 簡化模式簡報頁:簡報文字容器用 `white-space: pre-wrap`,內含的 `<brm-briefing-block>` 與角色 / 附件列要還原 `white-space: normal`
  (否則樣板的換行被畫成空白行,1366×768 上同儕評估提示被擠到捲動範圍外)。
- 簡化模式執行階段:側欄改直向 flex,各面板取自然高度、學員操作紀錄吃剩餘高度(至少 90 px),放不下時側欄捲動;

## 3. 改版面時的規則

1. 不縮小字級、不縮小觸控目標(按鈕 / 輸入框高度)來硬塞。例外是第 6 節列出、經第二十九輪審查接受的項目(1366×768 以上高 ≥ 44 px、寬 ≥ 32 px);
   比對時高度與寬度都要比(審查腳本 cmp2 的作法)。
2. 不用 `overflow: hidden`、`text-overflow: ellipsis` 把控制項或標籤裁掉來「通過」;內容放不下時讓所在的面板或欄**自己捲動**(`overflow-y: auto`)。
3. 關鍵控制(第 4 節清單)必須不捲動就看得到並點得到。
4. 不隱藏功能(教官小面板、警報按鈕等);窄時改排法。
5. 改完跑第 5 節的量測與端對端測試,並在 1366×768 與 1536×864 各看一張截圖。

## 4. 判定(端對端測試與開發量測共用)

# 本機資料位置 — 資料放 D: 或 G:,不放 C:

> 適用:Windows 開發機、船上筆電、教官筆電。訂於第二十八輪(2026-11-12,使用者指示);守則本文在 `CLAUDE.md`。

## 1. 守則

1. **所有要儲存在本機的資料都放在專案(安裝)資料夾內**,而這個資料夾放在 **D: 或 G:**(例如 `D:\Simosa BRM`、`G:\Simosa BRM`;可以是隨身碟)。程式與腳本不寫死磁碟代號,資料夾放在哪個磁碟就用哪個磁碟。
2. **C: 只放應用程式本身**(第 3 節)。
3. 某個項目放在隨身碟會**嚴重拖慢進度**時,**先取得訓練負責人同意**,才可以用第 4 節的例外開關把它放在 C:。沒有同意就維持預設。

**隨身碟的格式**:開發用(要執行 `pnpm install` 建置網頁)的磁碟必須是 **NTFS**。隨身碟出廠多為 exFAT 或 FAT32,不支援目錄連結,`pnpm install` 會以 `EISDIR` 失敗;FAT32 另有單檔 4 GB 上限(錄影、安裝檔)。FAT32 可用 `convert G: /FS:NTFS` 就地轉換(不清資料);exFAT 只能備份後重新格式化(會清空整顆磁碟,請先確認)。只執行發行版的船上 / 教官筆電不受這個限制。`setup-windows.ps1` 與 `check-local-data.ps1` 會檢查並提醒。

**環境變數怎麼生效**(開發機):

- `.\tools\setup-windows.ps1`:寫入使用者層級(之後開的終端機與 IDE 都生效)。**TEMP/TMP 例外**:只改目前這個 PowerShell 工作階段,不寫使用者層級(否則會影響這個帳號的所有程式,隨身碟拔除時其他程式會失敗)。
- `.\tools\setup-windows.ps1 -SessionOnly`,或雙擊 **`tools\dev-shell.cmd`**(開啟一個已設定好的 PowerShell 視窗):只設定那個視窗,不寫使用者層級。**專案在隨身碟時建議用這個方式** — 使用者層級的變數會讓這個 Windows 帳號的其他專案也把快取寫到隨身碟,拔除後它們會失敗;已寫入的可用 `.\tools\setup-windows.ps1 -Unregister` 移除。
- 直接在新開的終端機或 IDE 執行 `dotnet` / `pnpm` / `uv` 時,暫存檔仍會在 Windows 預設的 `C:\Users\…\AppData\Local\Temp`(TEMP 沒有寫成使用者層級):建置或測試請在 `dev-shell.cmd` 開的視窗內做,IDE 也從那個視窗啟動。
- `tools\` 下的建置與啟動腳本(`build-release.ps1`、`simosa-pkg.ps1`、`soak-test.ps1`、`start-ship-laptop.ps1`、`start-instructor-laptop.ps1`、`visual-run.ps1`、`visual-headless-check.ps1`)會自行設定,不必先執行 setup;已設定但指到專案外的值(例如專案從 D: 複製到 G: 後殘留的舊路徑)在該次執行改指回專案內。

## 3. 可以在 C: 的東西(應用程式與 Windows 自身)

- 應用程式的程式檔:.NET 8 SDK / 執行階段、Node.js、**corepack 下載的 pnpm 本體**(`%LOCALAPPDATA%\node\corepack`)、Git、uv、Microsoft Edge、WebView2 Runtime、Inno Setup、Arduino IDE 與其板套件 / 工具鏈、OpenCPN(多數也可以裝在專案磁碟的 `\Tools\`,見 `setup-windows.ps1` 結尾的建議)。
- Windows 自身的設定與紀錄:登錄(安裝程式只寫解除安裝資訊)、防火牆規則、網路介面設定、事件記錄與當機報告。
- 各應用程式自己的使用者設定檔(數 KB,無法或不適合改位置):NuGet 的 `%APPDATA%\NuGet\NuGet.Config`、Git 的 `%USERPROFILE%\.gitconfig`(`git lfs install`、`safe.directory` 都寫在這裡)與認證管理員、PowerShell 的指令歷史與模組快取、IDE 自己的設定與快取。
- 顯示卡驅動程式自己的著色器快取(NVIDIA / Intel / AMD;位置由驅動程式決定)。
- 安裝程式(`SimosaBRM-Setup-*.exe`)執行期間的暫存(Windows `%TEMP%`,結束即刪)。

## 4. 例外開關(每一個都要先取得同意)

| 想放 C: 的項目 | 開關 | 效果 |
|---|---|---|
| 暫存檔(建置、測試時的大量小檔;放隨身碟最容易拖慢) | `setup-windows.ps1 -SystemTemp`;腳本層級:環境變數 `SIMOSA_SYSTEM_TEMP=1` | TEMP/TMP 留在 Windows 預設的 `C:\Users\…\AppData\Local\Temp` |
| 整個專案資料夾 | `setup-windows.ps1 -AllowSystemDrive`;啟動與建置腳本的警告以環境變數 `SIMOSA_ALLOW_SYSTEM_DRIVE=1` 關閉 | setup 預設拒絕在系統磁碟執行;其他腳本在系統磁碟上會警告 |
| 安裝位置(安裝程式) | 確認對話框選「是」;靜默安裝加 `/ALLOWSYSTEMDRIVE=1` | 預設位置依序為 `D:\Simosa BRM`、`G:\Simosa BRM`;兩者皆無或自行改選系統磁碟時要求確認(預設「否」) |
| 瀏覽器端資料與下載的檔案 | `start-ship-laptop.ps1 -DefaultBrowser`、`start-instructor-laptop.ps1 -DefaultBrowser` | 用 Windows 預設瀏覽器開頁面,資料存在該瀏覽器位於 `C:\Users` 的設定檔,下載到 `C:\Users\…\Downloads`。找不到 Microsoft Edge 時腳本**不會**自動改用預設瀏覽器,只列出網址與這個開關 |
| simosa-pkg 的安裝根目錄 | `--root <路徑>` 或環境變數 `SIMOSA_INSTALL_ROOT` | 未指定時依序為:程式所在的安裝根目錄或專案根目錄(較近者)→ `D:\Simosa BRM` → `G:\Simosa BRM`(與系統磁碟同代號者略過);不會自動落到系統磁碟 |

## 5. 注意事項

- **視景請由啟動腳本啟動**(`start-ship-laptop.ps1`、`tools\visual-run.ps1`):直接雙擊 `app\visual\SimosaBRM.Visual.exe` 時,Godot 會把引擎 log 與著色器快取寫到 `C:\Users\…\AppData\Roaming\SimosaBRM-Visual`(Godot 匯出檔的使用者資料位置只能在啟動時用環境變數改)。
- **不要手動在其他瀏覽器輸入網址開教官站或講評報告站**:草稿、參與者資料與訓練紀錄會存進那個瀏覽器在 `C:\Users` 的設定檔,而且和啟動腳本開的視窗互不相通(外殼各頁、專屬 Edge 設定檔、其他瀏覽器是三處各自獨立的資料)。請用啟動腳本(專屬 Edge 設定檔)或 `-Shell`(WebView2 外殼);教官筆電執行 `start-instructor-laptop.ps1`。
- **先前用其他瀏覽器存過資料時的搬移**(一次性):以 `-DefaultBrowser` 啟動一次 → 在講評報告站與教官站把名冊、班次、評估表、教官與證書紀錄、情境草稿匯出成 JSON → 正常啟動(專屬 Edge 設定檔)後匯入 → 在舊瀏覽器清除 `127.0.0.1` 的網站資料。換開啟方式(外殼 ↔ Edge)時也一樣先匯出再匯入。
- 從網頁**下載**的檔案(情境 YAML、紀錄 JSON、講評報告與訓練紀錄匯出)存到 `build\downloads\`:WebView2 外殼每次啟動時設定;專屬 Edge 設定檔在第一次建立時預先寫入下載位置,之後每次啟動檢查 — 不在目前根目錄內(例如專案換了磁碟代號)就改回 `build\downloads`(該 Edge 視窗還開著時只警告)。講評報告用「列印 → 另存為 PDF」時,存檔對話框請選 `build\downloads`(WebView2 外殼的對話框預設資料夾可能是 `C:\Users` 下的文件或下載,尚未在實機確認)。
- **拔除隨身碟前**:執行 `stop-all.ps1`(會結束所有程序,並請以專屬設定檔開啟的 Edge 視窗關閉;`-KeepBrowser` 可保留),確認 Edge 視窗都已關閉。Edge 還開著就拔除會損毀設定檔內的草稿與訓練紀錄。開發機另可執行 `dotnet build-server shutdown`。
- 換磁碟代號或把專案複製到另一個磁碟(例如 D: → G:):開發機重新執行一次 `.\tools\setup-windows.ps1`(使用者層級的環境變數改指到新位置),或改用 `dev-shell.cmd`;啟動腳本與 Edge 的下載位置會自行修正。
- 解除安裝(安裝程式)只刪 `build\logs`、`build\tmp`;練習紀錄、設定、瀏覽器端資料(`build\webview2`、`build\browser`)與 `build\downloads` 都保留。
- pnpm 請用固定版 **10.28.0**(`corepack enable pnpm; corepack install -g pnpm@10.28.0`):11 以上不讀 `.npmrc` 的 `store-dir` / `cache-dir` / `state-dir`,快取與狀態會落到 `C:\Users\…\AppData\Local\pnpm-cache`、`pnpm-state`,而且 `pnpm install` 會失敗;`setup-windows.ps1` 偵測到時會警告。
- 尚未檢查寫入位置的手動用法:單獨執行 `SimosaBRM.Console.Serial`(log 寫到目前目錄的 `build\logs`)、`SimCore.Host --record <絕對路徑>`、`config\packaging.json` 的絕對路徑設定、外殼 `--profile <相對路徑>`。啟動腳本的用法都不會寫到根目錄外。

## 6. 在實機上確認

```powershell
.\tools\check-local-data.ps1                             # 開發機:檢查過去 24 小時
.\tools\check-local-data.ps1 -Since '2026-11-12 09:00'   # 檢查這個時間之後
.\app\launch\check-local-data.ps1                        # 安裝好的船上 / 教官筆電(發行版內的同一支腳本)
```

只讀取、不修改。它列出:

- 根目錄是否在系統磁碟、檔案系統(開發機須為 NTFS)、是否為抽取式磁碟;
- 開發機:目前工作階段的環境變數是否都指到專案內;
- 各工具「預設」會寫到 `C:\Users` 的位置是否有新資料(大小與最近寫入時間;以 Windows 的已知資料夾 API 取得真正的位置,不受目前終端機的環境變數影響);
- 專案內 `build\tmp`、`build\browser`、`build\webview2`、`build\downloads`、`.cache\godot\appdata` 的大小(僅供參考)。

根目錄沒有 `src\` 時自動以「安裝版模式」執行(只檢查執行期會寫的位置:視景使用者資料)。結束碼 0 = 沒有發現問題、1 = 有項目要處理、2 = 根目錄位於系統磁碟。

自動檢查(容器與 CI):`src/Tools.Calibration/tests/test_repo_datapaths.py`(設定檔、`setup-windows.ps1`、會執行 dotnet / Godot 的腳本都要導回暫存、檢查腳本的視景資料夾名稱)、`tools/launch/tests/launch-common.tests.ps1`(`Set-LaunchProjectEnv`、`Invoke-LaunchWithGodotUserDir`、瀏覽器設定檔與下載位置)、`tests/Tools.Packaging.Tests/InstallLayoutDefaultRootTests.cs`(預設安裝根目錄不落到系統磁碟)、`tools/installer/check-iss.py`(安裝程式預設位置、系統磁碟確認、解除安裝保留的資料)、`tools/pscheck.py`(`.ps1` 的 UTF-8 BOM)。Windows CI(執行器的工作目錄在 D:、系統磁碟為 C:,與實機配置相同)另做四件事:(1) 在 TEMP/TMP 指到 `build\tmp` 的配置下建置與測試;(2) 以內建的 Windows PowerShell 5.1 解析全部 `.ps1` 並實際執行 `setup-windows.ps1 -SessionOnly`、`check-local-data.ps1`、`build-release.ps1 -WhatIf`;(3) **依守則設定後,以專案內全新的 NuGet 快取還原並建置一個專案,`check-local-data.ps1 -Since <開始時間>` 必須回 0**(C: 上各工具的預設位置沒有新資料);(4) 以執行器上的 Inno Setup 實際編譯 `tools\installer\SimosaBRM.iss`(只驗證能編譯,不執行安裝)。

## 7. 尚未在 Windows 實機確認的項目

容器與 CI 無法涵蓋,第一次在實機上使用時請留意(有狀況請回報):

1. 專屬 Edge 設定檔:`--user-data-dir` 啟動、預先寫入的下載位置是否生效、`stop-all.ps1` 是否能關閉這些 Edge 視窗。
2. WebView2 外殼的下載位置(`build\downloads`)與「另存為 PDF」對話框的預設資料夾。
3. 匯出版視景(`app\visual\SimosaBRM.Visual.exe`)由啟動腳本啟動後,`C:\Users\…\AppData\Roaming\SimosaBRM-Visual` 沒有新檔、`.cache\godot\appdata\roaming\SimosaBRM-Visual\` 有 log。
4. 安裝程式(腳本已在 CI 以 Inno Setup 編譯通過;以下是執行時的行為):預設位置(D: → G:)、系統磁碟的確認對話框、靜默安裝的 `/ALLOWSYSTEMDRIVE=1`(靜默安裝未帶此參數時:同時帶 `/SUPPRESSMSGBOXES` 會中止,否則仍會跳出確認框)。安裝程式只以「磁碟是否存在」決定預設位置,D: 或 G: 若是光碟機、讀卡機或放安裝檔的隨身碟,請在選擇目錄頁自行改選。
5. exFAT / FAT32 隨身碟上的實際行為(`pnpm install` 失敗的訊息、Git 的 `safe.directory` 提示)。

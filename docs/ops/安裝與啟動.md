# 安裝與啟動 — 船上筆電與教官筆電

> 對應規劃書第 5.4 節(硬體配置)、第 5.5 節(船上部署、更新與資料回傳)、第 11.2 節(資料夾結構)、第 12.1 節 M4 交付(安裝程式)、第 14 章「船上部署」驗收列;需求 R13、R14;決策 D6、D19、D20。
> 發行版由 `tools/build-release.ps1`(Windows,win-x64)或 `tools/build-release.sh`(Linux/容器,linux-x64)產生;更新包與紀錄同步的設計見 `docs/design/packaging-sync.md`;視景見 `docs/design/visual-client.md`。
> 本文件描述**目前儲存庫可產生的發行版**:Windows 安裝程式(MSI/EXE)、USB 操控台服務(`Controls.Hid`)、Mumble VHF 與 OpenCPN 整合尚未實作,相關步驟標示「待實作」;WebView2 操船台外殼(`src\Shell.WebView2`,第 4.5 節)已實作(軟體),但只在 Linux 容器建置、未在 Windows 實機執行,首次上機依第 4.5 節第 6 項核對。

## 1. 發行版內容與資料夾結構

發行版目錄(`build/release/<版本>/`)即安裝後的根目錄內容;安裝就是把它複製到 `D:\Simosa BRM\`(規劃書第 11.2 節;**所有輸出都留在這個資料夾內,不寫 `C:\`**):

```
D:\Simosa BRM\
├─ app\                     軟體(簽章軟體更新包 kind=software 替換的元件)
│  ├─ simcore\              SimosaBRM.SimCore.Host.dll:50 Hz 核心、WebSocket 8765、UDP 多播 239.255.70.1:7001、NMEA UDP 10110 / 多播 239.192.0.1:60001
│  ├─ radar\                SimosaBRM.Sensors.Radar.Host.dll:雷達/ARPA,WebSocket 8766(/radar/x、/radar/s),NMEA TTM/TLL 10111/10112
│  ├─ web\                  網頁:index.html 儀器/操船台、instructor.html 教官站(?mode=simple 簡化教官模式、?mode=replay 重播)、radar.html、report.html
│  ├─ web-server\           simosa-web.dll:靜態網頁伺服(8080;只需 .NET 8 執行階段)

├─ tools\webview2\          README.txt + (岸上放入)MicrosoftEdgeWebView2RuntimeInstallerX64.exe:WebView2 Runtime Evergreen 離線安裝檔(第 4.5 節;不在儲存庫)
```

## 2. 船上筆電安裝(每船 1 台;岸上完成後上船)

### 2.1 作業系統與硬體

1. 機型與作業系統依規劃書第 5.4 節:內顯文書筆電、16 GB(建議 32 GB)、1 TB SSD、有線乙太網路埠;**Windows 11 IoT Enterprise LTSC 2024**(無功能更新、10 年安全更新)。於岸上完成啟用、每月累積更新與顯示卡驅動後再上船,之後不連網;若只能取得 Windows 11 Pro,功能版本支援到期日列入兩船版次清單並依第 5.5 節排程離線功能升級。
2. 安裝 .NET 8 執行階段(離線安裝檔);全碟加密(BitLocker,金鑰保管依公司程序;第 11.4 節)。
3. 建立 `D:\`(或把 `D:\Simosa BRM` 建在資料磁碟分割區);使用者帳號:岸上管理者(本機管理員)、船上帶領者/學員(標準使用者;第 9.1 節角色)。
4. 外接 24 吋螢幕(1080p)、USB 操控台、耳麥/桌面麥克風、USB 攝影機;放置於餐廳/會議室/船長辦公室,**不放駕駛台**;貼「訓練模擬器,非航行設備」標示(第 5.5 節)。

### 2.2 離線與網路隔離

- Wi-Fi 與藍牙:在 BIOS/UEFI 停用,或以裝置管理員停用並以群組原則禁止啟用;Windows Update 停用(LTSC 以 WSUS 離線或群組原則「不連線到任何 Windows Update 網際網路位置」)。
- 乙太網路埠只接教官筆電:介面命名為「直連-教官筆電」,**固定私有 IP**(不用 DHCP、不用鏈路本地位址):FSB1 `192.168.77.11/24`、FSB2 `192.168.77.12/24`,無閘道、無 DNS(`config\ship-laptop.json` 的 `network.adapterName/directLinkIp` 與之一致;啟動腳本以管理員執行時若 IP 不符會嘗試設定)。
- 不接船舶航儀網路(ECDIS、雷達、VDR、AIS、自動舵)、不接 NMEA 真實訊號;系統無任何出站需求,不設白名單。
- 防火牆:直連無 DHCP 與閘道,Windows 判為「無法辨識的網路」並套用**公用**設定檔,因此入站規則須涵蓋**全部設定檔**(以管理員 PowerShell 執行,只允許直連介面子網):

```powershell
$src = '192.168.77.0/24'
$rules = @(
  @{ Name = 'Simosa BRM 狀態 WebSocket';   Port = 8765;  Proto = 'TCP' },
  @{ Name = 'Simosa BRM 雷達 WebSocket';   Port = 8766;  Proto = 'TCP' },
  @{ Name = 'Simosa BRM 網頁';            Port = 8080;  Proto = 'TCP' },
  @{ Name = 'Simosa BRM 直連同步';        Port = 7300;  Proto = 'TCP' },
  @{ Name = 'Simosa BRM 狀態多播';        Port = 7001;  Proto = 'UDP' },
  @{ Name = 'Simosa BRM NMEA 多播';       Port = 60001; Proto = 'UDP' },
  @{ Name = 'Simosa BRM NMEA 單播';       Port = '10110-10112'; Proto = 'UDP' }
)
foreach ($r in $rules) {
  New-NetFirewallRule -DisplayName $r.Name -Direction Inbound -Action Allow -Profile Any -Protocol $r.Proto -LocalPort $r.Port -RemoteAddress $src -Program Any | Out-Null
}
```
Mumble VHF 埠(64738)待語音模組實作後再加;多播收發由 SimCore.Host 綁定直連介面(規劃書第 5.4 節;目前 Host 以 `--multicast` 設群組與埠,介面綁定依作業系統路由,安裝後以教官筆電驗證多播可收到)。

### 2.3 USB 裝置管制

依第 5.5 節:以群組原則「可移除儲存裝置存取」拒絕所有可移除磁碟的讀/寫/執行,再以裝置安裝限制(裝置 ID 允許清單)只允許登錄的操控台 HID、鍵鼠、耳麥/麥克風、USB 攝影機、USB-C 乙太網路轉接器與**公司登錄的專用隨身碟**(以硬體 ID 登錄);停用自動播放;啟用「可移除儲存裝置」稽核(事件 ID 6416 裝置連接)並由紀錄包回傳(**待實作**:目前紀錄包只含練習紀錄與報告,USB 事件匯出列入待辦)。專用隨身碟每次插入前於岸上以更新的防毒掃描。

### 2.4 複製發行版並核對

1. 用專用隨身碟(或岸上網路)把發行版目錄複製到 `D:\Simosa BRM\`。
2. 核對清單(每檔 SHA-256):
   ```powershell
   cd "D:\Simosa BRM"
   dotnet tools\updater\simosa-pkg.dll release verify --dir .
   ```
   列出任何「不符/缺少/多出」即重新複製。
3. 設定檔:
   - `copy config\ship-laptop.json` 後依本機修改 `shipId`、`deviceId`、`network.directLinkIp`、`visual.views`(螢幕索引)、`simcore.scenario`(預設練習)。
   - `copy config\packaging.ship.example.json config\packaging.json`,改 `shipId`、`deviceId`、`listen`。

### 2.5 信任清單與裝置金鑰(規劃書第 5.5 節、packaging-sync.md 第 2、6.1 節)

```powershell
cd "D:\Simosa BRM"
$pkg = 'dotnet tools\updater\simosa-pkg.dll'
# 主金鑰與備援金鑰的「公鑰」PEM(由硬體金鑰匯出;正式金鑰絕不以檔案存在筆電)
& dotnet tools\updater\simosa-pkg.dll trust add --root . --file primary.pub.pem --admin 安裝人員
& dotnet tools\updater\simosa-pkg.dll trust add --root . --file backup.pub.pem  --admin 安裝人員
# 裝置金鑰(DPAPI 綁定本機帳號;紀錄包與直連握手用)
& dotnet tools\updater\simosa-pkg.dll device init --root . --ship FSB1 --device-id FSB1-LT01
& dotnet tools\updater\simosa-pkg.dll device show --root .     # 公鑰帶回教官筆電登錄
& dotnet tools\updater\simosa-pkg.dll status --root .
```
`status` 應列出兩把信任金鑰(主、備援)、船舶/裝置 ID、「初始安裝,尚未套用更新包」。開發/測試環境可用 `build\release\dev-keys\` 的開發金鑰,但**不得**放進船上系統映像。

### 2.6 首次啟動與驗收項目

```powershell
cd "D:\Simosa BRM"
.\app\launch\start-ship-laptop.ps1 -CheckOnly     # 列出找到的元件
.\app\launch\start-ship-laptop.ps1                # 啟動全部;前景等待 Ctrl+C
```
確認:`build\logs\simcore.log` 每秒一行狀態且 `steps/s 50`(核心 50 Hz 無掉拍);瀏覽器開 `http://127.0.0.1:8080/instructor.html?mode=simple` 可載入情境並開始;`radar.html` 有回波;視景視窗在指定螢幕;`build\logs\sync.log` 顯示「船端同步服務 FSB1 監聽 192.168.77.11:7300」。接著依第 14 章「船上部署」列:船舶電源下連續執行 2 小時、拔電源後電池續跑 ≥ 15 分鐘並確認 `build\records\*.jsonl` 完整(footer),教官筆電接線後 1 分鐘內可連線(第 3.4 節)。

## 3. 教官筆電安裝(訪船船長,1 台)

1. Windows 11 Pro(可連公司網路取得每月修補並備份紀錄庫)、32 GB、2 TB SSD、.NET 8 執行階段、全碟加密;岸上連網用 Wi-Fi,**直連埠固定 IP `192.168.77.21/24`**(介面命名「直連-船上筆電」)。
2. 複製發行版到 `D:\Simosa BRM\` 並 `release verify`(同第 2.4 節);`config\instructor-laptop.json` 依本機修改;`copy config\packaging.instructor.example.json config\packaging.json`。
3. 登錄兩船裝置公鑰(第 2.5 節 `device show` 輸出):
   ```powershell
   dotnet tools\updater\simosa-pkg.dll store register-device --root . --ship FSB1 --device FSB1-LT01 --public FSB1-LT01.pub.pem
   ```
4. 硬體金鑰(智慧卡/PIV 安全金鑰)經 Windows 迷你驅動程式登錄後,憑證在 `CurrentUser\My`;`simosa-pkg key-info --cert <指紋>` 顯示金鑰 ID,與船上信任清單的主金鑰 ID 相符。備援金鑰由 DPA/海務主管另機保管。
5. 防火牆:教官筆電為客戶端,入站只需多播 UDP 7001/60001(由船上送出)與視景/雷達鏡像無入站;Wi-Fi/藍牙在直連時停用(`start-instructor-laptop.ps1 -CheckWifi` 會在 Wi-Fi 啟用時拒絕進入直連模式;第 14 章)。

## 4. 日常啟動與關閉

### 4.1 船上(簡化教官模式;船長或帶領者)

1. 開機 → 登入船上帶領者帳號 → 雙擊 `app\launch\start-ship-laptop.ps1`(或桌面捷徑:`powershell -ExecutionPolicy Bypass -File "D:\Simosa BRM\app\launch\start-ship-laptop.ps1"`;加 `-Shell` 以 WebView2 外殼全螢幕開啟網頁而不用瀏覽器,第 4.5 節)。腳本依 `config\ship-laptop.json` 啟動 SimCore.Host → 雷達 → 網頁 → 視景(每個 `visual.views[]` 一個程序,`--view/--monitor`)→ 同步服務,並開啟 `web.openPages` 的頁面(預設瀏覽器;`-Shell` 或 `web.shell: true` 時為外殼);各程序 log 在 `build\logs\`。
2. 練習前:帶領者在教官站「參與者與休息時間確認」面板填參與者並確認已核對船上工時/休息時間紀錄(第 5.5 節「休息時間相容」);按「確認並送出」後核心以 `sessionInfo` 寫進紀錄標頭(或已開啟紀錄的 `session` 行),紀錄包的訓練時數即依此彙總並隨紀錄包回傳。
3. 練習:選擇情境 → 簡報 → 開始 → 標記 → 結束練習 → 講評摘要 → 「下載紀錄 JSON」(核心紀錄已自動寫到 `build\records\`)。
4. 關閉:在啟動視窗按 **Ctrl+C**,或執行 `app\launch\stop-all.ps1`(先寫停止檔 `build\logs\simcore.stop` 讓核心自行結束練習並寫完紀錄 footer,最多等 10 s,逾時才強制結束;教官站/本機客戶端送 WebSocket `shutdown` 指令亦走同一流程:結束練習 → footer → 程序結束)。建議仍先在教官站「結束練習」定稿講評摘要;只有被強制結束(逾時、斷電)的紀錄才會缺 footer,紀錄包會標示完整性不符。

### 4.2 教官筆電(訪船)

1. 停用 Wi-Fi/藍牙 → 接網路線到船上筆電 → `app\launch\start-instructor-laptop.ps1 -Ship FSB1 -CheckWifi`:檢查無線介面、確認 `ws://192.168.77.11:8765` 可連線、啟動本機網頁伺服並開啟教官站(`instructor.html?ws=ws://192.168.77.11:8765`)、雷達鏡像(`radar.html?ws=ws://192.168.77.11:8766`)、講評報告頁;印出同步指令。
2. 有評估的練習:完整教官站監看、事件注入、BRM 標記;結束後 `report.html` 產生評估表/講評報告/個人訓練紀錄。
3. 同步(第 5 節;推軟體更新包前船上先 `stop-all.ps1 -KeepSync`)→ 拔線 → `stop-all.ps1`。Linux 開發版:`start-instructor-laptop.sh --ship FSB1|<IP> --check-wifi`。
4. 離船備課:`start-instructor-laptop.ps1 -Standalone`(本機 SimCore + 雷達,`standalone` 區段設定情境)。

### 4.3 多螢幕與視景品質

`config\ship-laptop.json` 的 `visual.views[]`:`{ "view": "bridge", "monitor": 1, "fullscreen": true }`,可加 `portWing`/`stbdWing`(每顯示器一個程序;docs/design/visual-client.md 第 7 節)。`visual.quality`:`auto`(偵測 GPU/記憶體並依實測幀率自動降級,結果記在 `build\visual\quality.json`,下次啟動自動以 Compatibility 渲染器啟動低品質)、`low`/`mid`/`high`。第 14 章效能驗收(內顯 1080p ≥ 30 fps)的實測步驟見該文件第 10 節。

### 4.4 視景未匯出時

本輪發行版若 `app\visual\` 不存在(manifest.json `components.visual.status` 為「略過:缺匯出範本」),船上筆電需另安裝 Godot 4.5.1 .NET 編輯器(自含模式:放在 `D:\Simosa BRM\.cache\godot\4.5.1\` 並建立空檔 `_sc_`,使用者資料留在該目錄;visual-client.md 第 8 節)與原始碼 `src\Visual.Godot`、`src\Visual.Shared`,`config\ship-laptop.json` 的 `visual.godotEditor` 指向編輯器,啟動腳本會以 `--path src\Visual.Godot` 執行。取得 `Godot_v4.5.1-stable_mono_export_templates.tpz` 後以 `tools\build-release.ps1`(自動偵測範本)重新發行即可改為匯出檔。

### 4.5 WebView2 操船台外殼(kiosk;`app\shell\SimosaBRM.Shell.exe`)

船上筆電可不開瀏覽器,改以單一桌面程式全螢幕顯示操船台/教官站/雷達/報告站網頁(規劃書第 5.2 節 Instruments「WebView2 殼」、第 5.4 節兩螢幕配置 D6、第 5.5 節「WebView2 採固定版本隨應用程式散布並隨軟體更新包更新」)。原始碼 `src\Shell.WebView2`(WinForms,net8.0-windows,NuGet `Microsoft.Web.WebView2` 固定版號)+ `src\Shell.Core`(參數 → 網址、Runtime 訊息、重試退避、路徑;`tests\Shell.Core.Tests` 在 Linux 可測);`tools\build-release.ps1`(或 `.sh --rid win-x64`)發布到 `app\shell\`,Linux 預設發行版只建置不發布(manifest.json 的 `shell` 元件註記「略過:非 win-x64」)。**本輪只在 Linux 容器以 EnableWindowsTargeting 建置與單元測試,未在 Windows 實機執行;首次上機依第 6 項核對。**

1. **執行階段(全部離線)**:除 .NET 8 執行階段外另需 **.NET 8 Desktop Runtime**(`dotnet --list-runtimes` 須列出 `Microsoft.WindowsDesktop.App 8.x`;離線安裝檔 `windowsdesktop-runtime-8.x.x-win-x64.exe`)與 **Microsoft Edge WebView2 Runtime**。Windows 11 與 Windows 10 近期版本多半已內建 Evergreen Runtime(`HKLM\SOFTWARE\WOW6432Node\Microsoft\EdgeUpdate\Clients\{F3017226-FE2A-4295-8BDF-00C3A9A7E4C5}` 的 `pv` 為版本),LTSC 或精簡映像可能沒有。岸上自 Microsoft「WebView2 Runtime」下載頁取得 **Evergreen Standalone Installer(x64)** `MicrosoftEdgeWebView2RuntimeInstallerX64.exe`(約 150 MB,完全離線可裝;**不要用 Bootstrapper**,它需要網際網路),放到發行版 `tools\webview2\`(與該目錄的 README.txt 同處)或登錄的更新隨身碟;上船後以系統管理員執行 `MicrosoftEdgeWebView2RuntimeInstallerX64.exe /silent /install`。外殼啟動時偵測不到 Runtime 會以中文顯示這個路徑與步驟,安裝後按「重試」即可。Runtime 版次(登錄檔 `pv`,或 `build\logs\shell-*.log` 第一行「WebView2 Runtime <版本>」)登錄到兩船版次清單(第 5.5 節;**本輪尚未自動寫入 manifest.json/版次清單**,見第 7 節);Runtime 須不低於 SDK 發行說明所列的最低版本(SDK 版號見 `src\Shell.WebView2\Shell.WebView2.csproj`,1.0.3351.48 對應 Runtime 133.x 以上,以 Microsoft 的 SDK 發行說明為準);Runtime 的更新與每月安全更新一樣由岸上驗證後隨更新包派送。
2. **啟動**:`start-ship-laptop.ps1 -Shell`(或 `config\ship-laptop.json` 的 `web.shell: true`;`web.shellMonitors` 指定各頁螢幕):`web.openPages` 每一頁各開一個外殼程序(`--url http://127.0.0.1:8080/<頁> --kiosk --no-close-confirm [--monitor n]`),PID 記入 `build\logs\simosa.pids`、log 為 `build\logs\shell-<頁>.log`,`stop-all.ps1`/Ctrl+C 一併結束(`--no-close-confirm` 使 `stop-all.ps1` 的 CloseMainWindow 不彈確認對話框;手動啟動的外殼仍會詢問);找不到 `app\shell\SimosaBRM.Shell.exe`(或開發建置 `build\bin\Shell.WebView2\Release\net8.0-windows\`)時退回預設瀏覽器並警告。也可直接執行,例如操船台:
   `app\shell\SimosaBRM.Shell.exe --page conning --station bridge --ws ws://127.0.0.1:8765 --kiosk --monitor 0`
   參數:`--page conning|instructor|radar|report`(index/instructor/radar/report.html)、`--station bridge|portWing|stbdWing|ecr`(→ `?station=`,警報面板的確認/轉移依此)、`--mode simple|full|replay`(教官站 `?mode=`;未給時 simple)、`--radar x|s`、`--ws ws://主機:8765|8766`(→ `?ws=`)、`--base`(網頁伺服,預設 `http://127.0.0.1:8080`)、`--url`(完整網址,優先;頁面/站別由網址推斷)、`--monitor <n>`(0 起算;D6 兩螢幕:視景在 1、操船台在 0)、`--profile <資料夾>`、`--allow-devtools`、`--help`;參數錯誤時顯示用法並以結束碼 2 離開。教官筆電也可用:`--page instructor --mode full --ws ws://192.168.77.11:8765 --base http://127.0.0.1:8080`。
3. **kiosk 行為**:無邊框全螢幕、最上層;**F11** 切換全螢幕/視窗、**F5** 重新載入、**Esc** 不離開(按鍵交給網頁)、**Alt+F4**/關閉鈕跳出確認(練習中誤關防護;Windows 關機/登出不詢問);右鍵選單、DevTools、瀏覽器快捷鍵、縮放、自動填入關閉(`--allow-devtools` 開啟前兩者);`target=_blank` 留在同一視窗;網頁伺服尚未啟動或斷線時頂端狀態列顯示「載入失敗(第 n 次),m 秒後重試」並以 1→2→4→8→15 s 退避自動重試,成功即隱藏;視窗標題「Simosa BRM 操船台 — 駕駛台 bridge」「Simosa BRM 教官站 — simple」等;警報聲免先點擊(`--autoplay-policy=no-user-gesture-required`)。視窗關閉即結束程式。
4. **資料位置(不寫 `C:\`)**:WebView2 使用者資料夾預設 `build\webview2\<conning-bridge|instructor|radar-x|report>\`(每個外殼各一個,`--profile` 可改);log `build\logs\shell-<同名>.log`(啟動參數、Runtime 版次、重試、關閉)。清快取:關閉外殼後刪該資料夾。
5. **自動登入與開機啟動(作業系統設定,不在本軟體內)**:船上帶領者帳號自動登入用 Windows 的 `netplwiz`(或 Sysinternals Autologon,密碼存於 LSA 而非明文登錄檔);開機啟動用「工作排程器」於「登入時」執行 `powershell -ExecutionPolicy Bypass -File "D:\Simosa BRM\app\launch\start-ship-laptop.ps1" -Shell`(或捷徑放 `shell:startup`);需要只剩操船台畫面時,以 Windows「指派的存取」/Shell Launcher(Enterprise/IoT LTSC)把外殼或啟動腳本設為該帳號的殼程式。這些與 USB 管制、防火牆同為第 2.2–2.3 節的系統映像項目,安裝驗收時逐項核對。
6. **實機核對項目**(Windows 10/11;第 14 章「船上部署」列,需實機):Runtime 未安裝時顯示中文說明與正確的 `tools\webview2\…` 路徑 → 安裝後「重試」可顯示;兩螢幕 `--monitor 0/1` 位置正確;F11/F5/Esc/Alt+F4 行為如第 3 項;網頁伺服晚於外殼啟動時自動重試成功;警報聲免點擊;`stop-all.ps1` 能結束外殼;`build\webview2\` 與 `build\logs\shell-*.log` 確實在安裝根目錄內、`C:\Users` 無 WebView2 資料夾;報告站「列印 / 另存 PDF」在外殼內可用。

## 5. 更新包套用與紀錄回傳(規劃書第 5.5 節;詳見 docs/design/packaging-sync.md 第 6 節)

### 5.1 岸上產生更新包(教官筆電)

- 軟體:發行版自帶 `packages\simosa-<版本>-software.sbupd` 為**開發金鑰**簽章(僅供測試);正式派送由訓練負責人以硬體金鑰重新簽章:
  ```powershell
  dotnet tools\updater\simosa-pkg.dll pack --kind software --version <版本> --summary "軟體 <版本>" --dir app=D:\release\<版本>\app --cert <憑證指紋> --out build\packages\software-<版本>.sbupd
  ```
- 程序參數/情境(R14;第 9.1 節):`impact` → 重新驗證受影響情境並 `verification add` → `pack --kind parameters|scenarios --sms <編號>:<版次>:<核准人>`;未驗證者無法產生(`--force` 產生的包船上預設拒絕)。
- 信任金鑰更換:備援金鑰簽章 `pack --kind trust`(packaging-sync.md 第 6.5 節)。

### 5.2 訪船直連同步(一鍵)

```powershell
dotnet tools\updater\simosa-pkg.dll sync --ship FSB1 --cert <憑證指紋> --push build\packages\software-<版本>.sbupd --push build\packages\params-<版本>.sbupd
```
流程:雙向驗證握手 → 依版本推送更新包(船上 verify → 原子套用,顯示簽章者與版次;失敗自動完整回復)→ 取回紀錄包(`.sbrec`,裝置金鑰簽章)→ 送「已備份回報」(上次備份完成者)→ 船上刪除已備份副本 → 更新 `store\fleet-versions.json`。**套用軟體更新包時船上模擬器須已關閉但同步服務仍要在執行**:船上先執行 `app\launch\stop-all.ps1 -KeepSync`(Linux:`stop-all.sh --keep-sync`)— 結束核心、雷達、網頁、視景,只保留 `simosa-pkg serve`(7300)與其 PID 列(不帶 `-KeepSync` 的 `stop-all` 會把同步服務一併結束,教官筆電的 `sync` 會連不上);教官筆電再執行上面的 `sync`;套用後船上重新 `start-ship-laptop.ps1`(啟動時會先結束保留的同步服務再重新啟動全部)。
船上顯示現行版次:`simosa-pkg status`(簡報與講評報告顯示參數集版次與 SMS 文件版次)。回復上一版:`simosa-pkg rollback`。

### 5.3 回岸後備份與回報

`simosa-pkg store backup --to E:\`(加密外接碟,逐檔核對雜湊並標記已備份);下次訪船 `sync` 自動送已備份回報,船上才刪除副本。未取得回報的紀錄船上最多累積 2 個訪船間隔(`maxVisitIntervals`),超過時 `status` 與同步回報警告但不自動刪除。

### 5.4 隨身碟備援

教官:`simosa-pkg export --to F:\ --role instructor --push <更新包> --cert <指紋>`;船上:`simosa-pkg import --from F:\ --role ship`(套用更新包、處理回報、把待回傳紀錄包寫回);教官:`simosa-pkg import --from F:\ --role instructor`。隨身碟上只有簽章檔。

## 6. 故障排除

| 現象 | 檢查 | 處理 |
|---|---|---|
| `start-ship-laptop.ps1` 顯示「找不到 dotnet」 | `dotnet --list-runtimes` | 安裝 .NET 8 執行階段(離線安裝檔);或 `DOTNET_ROOT` 指向安裝位置 |
| 「埠 8765 已被占用(SimCore ws)」(啟動前檢查;雷達 8766、網頁 8080、同步 7300 同) | `netstat -ano \| findstr :8765`(Linux:`ss -ltnp \| grep :8765`) | 殘留的舊核心或其他程式占住埠:`stop-all.ps1`;PID 檔遺失時以工作管理員結束該 PID 的 `dotnet` |
| 「SimCore.Host 已結束(啟動失敗)」 | `build\logs\simcore.log`、`simcore.err.log`(上一次的在 `simcore.1.log`) | 情境載入失敗(YAML 錯誤:`dotnet app\simcore\SimosaBRM.SimCore.Host.dll --scenario <檔> --validate`)、係數檔缺少(`data\ships\<ID>\coefficients.<loading>.json`) |
| 「SimCore.Host 未在 30 s 內開啟 ws 埠」 | `build\logs\simcore.log` | 程序仍在但未開埠:機器過慢或防火牆攔截本機連線;`--validate` 檢查情境 |
| 教官站顯示「未連線」 | 網址 `?ws=` 是否指向船上 IP;船上 `netstat -an | findstr 8765` | 防火牆規則(第 2.2 節)、固定 IP 是否生效(`ipconfig`)、網路線 |
| 雷達頁無回波 | `build\logs\radar.log` 是否「客戶端連線」 | 雷達服務需先連到核心 `ws://127.0.0.1:8765`;`radar.html?ws=ws://<船上 IP>:8766` |
| 視景黑畫面/幀率低 | `build\visual\quality.log` | 改 `visual.quality` 為 `low`;確認外接螢幕索引;內顯驅動為岸上驗證版本 |
| `simosa-pkg verify` 拒絕更新包 | 錯誤訊息:未信任金鑰 / 版本不大於曾套用最高版本 / 驗證狀態 forced / 船舶限定 | 以信任金鑰重新簽章;版本遞增;重新驗證情境;確認 `--ship` |
| `sync` 握手失敗 `untrusted-key` / `auth-failed` | 船上 `state\audit.jsonl` 的 `sync.auth.failed` | 教官金鑰未在船上信任清單(以備援金鑰派送 trust 包或管理者 `trust add`);裝置未登錄(教官 `store register-device`) |
| 套用後程式無法啟動 | `simosa-pkg status` 的 `rollbackAvailable` | `simosa-pkg rollback`,記入稽核;回報開發者附 `state\audit.jsonl` |
| 紀錄包標示完整性不符 | 紀錄檔是否有 footer;`simcore.log` 結尾是否有「紀錄已關閉」與「結束(原因:…)」 | 以 `stop-all`(停止檔)、Ctrl+C 或教官站 `shutdown` 正常結束,核心會寫完 footer;只有逾時強制結束或斷電的紀錄缺 footer,仍回傳但標示 |
| 多播收不到(OpenCPN/外接設備) | `--multicast`、介面綁定 | 目前 Host 依作業系統路由送多播;必要時在船上筆電加路由 `route add 239.0.0.0 mask 255.0.0.0 192.168.77.11` |
| Ctrl+C 後仍有程序 | `build\logs\simosa.pids` | `stop-all.ps1`;仍在時工作管理員結束 `dotnet` / `SimosaBRM.Visual` |
| `sync` 握手「連線被拒」(7300 無監聽) | 船上 `build\logs\sync.log`、`simosa.pids` 是否有 `sync:` 列 | 船上曾以不帶 `-KeepSync` 的 `stop-all` 關閉:重新 `start-ship-laptop.ps1` 後再 `stop-all.ps1 -KeepSync`,或單獨 `dotnet tools\updater\simosa-pkg.dll serve --root .` |
| 外殼顯示「尚未安裝 WebView2 Runtime」或「缺少 WebView2Loader.dll」 | `build\logs\shell-*.log`;`app\shell\` 是否有 `WebView2Loader.dll` | 第 4.5 節第 1 項離線安裝 Runtime 後按「重試」;缺 dll 時以 manifest.json 重新核對/複製 `app\shell\`;暫時改用不帶 `-Shell` 的瀏覽器啟動 |
| 外殼一直顯示「載入失敗…重試」 | `build\logs\web.log`(simosa-web 是否在 8080)、`shell-*.log` 的 WebErrorStatus | 網頁伺服未啟動或埠被改:確認 `config\ship-laptop.json` `ports.web` 與外殼 `--base`/`--url` 一致;外殼會持續自動重試,不需重開 |

稽核與 log 位置:`build\logs\<元件>.log`(各程序;Windows 版每次啟動輪替保留上 3 次為 `<元件>.1.log`…`.3.log`,`launch.log` 為每次啟動的時間、PID、指令與參數;Linux 版同檔追加)、`state\audit.jsonl`(更新/同步/紀錄事件)、`build\records\*.jsonl`(練習紀錄)、`build\visual\quality.log`。回報問題時附上這些檔案與 `manifest.json` 的版本/git 版次。
啟動腳本的自動測試:`tools/launch/tests/launch-tests.sh`(Linux/容器:埠占用、SimCore 啟動失敗、`--keep-sync`、`--logs`、`--ship <IP>`、`--check-wifi`、simosa-web 關閉)與 `tools/launch/tests/launch-common.tests.ps1`(`pwsh -NoProfile -File …`:log 輪替、埠檢查、`-KeepSync`)。

# 中塑海運內部 BRM 複訓課程大綱(FS Bitumen No.1 / No.2)

> **本課程為公司內部訓練(規劃書第 1.4 節模式 A、D1),不取代航港局或船旗國核發的法定 BRM/領導統御專業訓練證書;完成紀錄為「內部訓練聲明」,不是法定證書(第 8 節)。**
> 依據:規劃書第 2.1–2.3 節(STCW A-II/1、A-II/2、A-VIII/2、IMO 示範課程 1.22/1.39)、第 8.0 節(訓練形式與週期)、第 8.1 節(練習目錄)、第 8.4 節(講評)、第 5.5 節(休息時間相容);情境設計 `docs/design/scenario-library.md`、`docs/design/ship-familiarisation.md`;評估方式見 `docs/訓練/評估者指引.md`;法規對照見 `docs/驗收/STCW-A-I-12-與-DNV-對照.md`。
> 版本:v0.1(2026-10-23,草案);核准人:待訓練負責人(訪船船長)核准並由 DPA 或海務主管納入 SMS 訓練程序(D20)。時數、排程與通過準則凡標 ASSUMED 者集中於第 10 節。

## 1. 課程目的與定位

| 項目 | 內容 |
|---|---|
| 目的 | 在 5 年複訓週期內(D19,與法定證書換證同步)維持並驗證兩船駕駛台團隊的非技術技能:領導、狀況覺知、溝通、團隊合作、決策(規劃書第 8.2 節五大類),並以兩船實際操縱特性與公司程序(`data/parameters/company-procedures.yaml`)為情境基礎 |
| 課程形式 | 航次中的模組化練習(第 8.0 節):每個練習含簡報、執行、講評,1.5–2 小時;有評估的練習(E01、E20)由訪船船長於訪船期間執行,其餘由船長以簡化教官模式帶領 |
| 三種課程 | (A) 完整課程:首次參加者,10–14 個練習;(B) 定期複訓:每 5 年,5–6 個練習;(C) 船舶熟悉:新進或調船人員,F01–F03。靠離泊預演與持續練習為課程外的運用形式(第 3.4 節) |

| 證據用途 | TMSA 5.1.3、5.4.3 與 SIRE 2.0 的內部訓練證據;**不**作為 TMSA 5.4.4「認可機構複訓」的證據(第 1.4 節,D2 未啟動) |

| 評估類型 | 何時 | 工具 | 判定 | 備註 |
|---|---|---|---|---|
| 基線評估(形成性) | E01 | 行為標記表(5 類 × 3 要素,1–5 分)+ 自動指標 | 不判通過,作為 E20 比較基線(Kirkpatrick L2) | 訪船船長評分 |
| 練習講評(形成性) | 每個練習 | BRM 快速標記(`brm-markers.ts` 五類、plus/delta)、講評報告 `report.html`、自動指標 | 不判通過;講評至少完成反應階段與團隊自我回顧(第 8.1 節) | 船長帶領;訪船船長事後依紀錄補充 |
| 迷你情境討論 | E22a–d | 情境必要事件(例如 `conflictQuery`、`challengeMaster`)+ 討論點 | 不評分;紀錄出席與討論摘要 | 船長帶領 |
| 總結性評估 | E20 | 行為標記表 + 自動指標(硬性失敗、容許帶、必要事件;`assessment.passMark`)| 評估員依「安全有效完成任務」判定通過/未通過(評估者指引第 7 節) | 訪船船長主評、船長第二評;雙評一致率 ≥80% |
| 課後問卷(L1) | 每期結束 | 問卷(訪船船長、船長、學員) | 目標 ≥4/5(第 14 章課程列) | 紙本或講評站表單 |
| 課程成效(L3/L4) | 課後 3–6 個月;年度 | 航行稽核、SIRE 人員觀察、近失率 | 由訓練負責人彙整,不在系統內 | 規劃書第 8.4 節 |

通過準則(ASSUMED):E20 無硬性失敗(擱淺、碰撞、CPA/UKC 門檻)、自動評分 ≥ `assessment.passMark`(目前 70),且 15 項要素無 1 分、2 分以下要素 ≤3 項並均附時間戳觀察;評估員最終判定優先於自動評分。未通過者本版僅記錄與講評(D20)。

## 6. 排程與休息時間

### 6.1 在航排程(船長帶領)

| 項目 | 規定 |
|---|---|
| 頻率 | 每週 1–2 個練習(完整課程);複訓 2–4 週內 3–4 個 |
| 時段 | 非當值時段;禁止於當值、靠離泊作業與貨物作業關鍵時段(第 5.5 節);避免 00–06 時(ASSUMED) |
| 長度 | ≤2 小時(含簡報/講評);E22 四段可分兩天 |
| 休息時間(STCW A-VIII/1、MLC 2006 規則 2.3) | 練習時間計入工作時間;每位參與者仍須任何 24 小時內 ≥10 小時休息、任何 7 日內 ≥77 小時休息;休息最多分兩段,其中一段 ≥6 小時,兩段休息間隔 ≤14 小時 |
| 練習前確認 | 帶領者在教官站「參與者與休息時間確認」面板(`session-info-panel.ts`,`restHoursConfirmation`)確認已對照船上工時/休息時間紀錄;確認隨紀錄包回傳(R9/R13) |
| 人力 | 每個練習包標明需扮演的角色與最少人數(第 9.1 節);不足時改用純語音腳本版本或留待訪船 |
| 事後 | 訓練時數(每位參與者起訖)由紀錄包匯出,轉錄至船上工時/休息時間紀錄 |

### 6.2 在港/訪船排程(訪船船長帶領)

| 項目 | 規定 |
|---|---|
| 時機 | 訪船船長每船每 1–2 個月訪船 1 次,於麥寮裝貨或卸貨港停泊 1–2 天(D17 確認) |
| 內容 | 第一次訪船:E01 評估 + 開課;第二次訪船:E20 評估 + 補充講評 + 船上帶領者再校準(需要時) |
| 時段 | 避開靠離泊、貨物作業關鍵時段與 PSC/SIRE 檢查;每人每日 ≤1 個有評估的練習(ASSUMED) |
| 休息時間 | 同 6.1;港內工作負荷高,帶領者須於排程前確認當日貨物作業班表 |
| 設備 | 教官筆電以網路線直連船上筆電(1 分鐘內連線,第 14 章船上部署列);紀錄包與更新包同次同步 |

## 3. 開發環境備註

- 雲端容器:.NET SDK 以 conda-forge 套件安裝在 `/opt/dotnet`(`. /etc/profile.d/dotnet.sh`,`DOTNET_ROLL_FORWARD=Major` 執行 net8.0);Microsoft 下載主機(`dot.net`、`builds.dotnet.microsoft.com`)被環境網路政策擋住,若要用官方安裝腳本需在環境的 Network access 設定允許。nuget.org、PyPI、npm、conda-forge 可連。
- Windows(`D:\Simosa BRM`):先執行 `tools/setup-windows.ps1`,所有快取/輸出留在專案內(`.cache\`、`build\`)。
- 暫存腳本(Playwright 驗證、WebSocket 探測)位於雲端工作階段的 scratchpad,**不在儲存庫**,容器回收後消失;需要時重寫(教官站 README 有驗證流程說明)。
